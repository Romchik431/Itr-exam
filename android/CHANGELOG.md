# Изменения

## 1.0.0

Первый подписанный выпуск Android. Сохранены оригинальная нумерация, варианты, исходные ключи, комментарии и связь со страницами источника. Добавлены мобильные режимы обучения, экзамена, исправления ошибок, карточки, план, заметки и версии баз. Приложение использует локальный синтез речи, системный выбор файлов, резервные копии, уведомления и экспорт результатов. При подсчёте балла проверяются ID вариантов, при восстановлении таймера учитывается реальное время окончания. Добавлен отдельный фильтр вопросов с датированной индивидуальной проверкой.
