# Базы и обновления

В «Меню → Экзаменационные базы» выберите «Импорт базы JSON». Приложение покажет дисциплину, редакцию, количество вопросов и повторов формулировок до подтверждения. Для получения полного рабочего примера экспортируйте активную базу из этого же раздела. Файл передаётся в UTF-8. Максимальный размер импортируемого документа — 24 МиБ.

```json
{
  "format": "exampro.bank",
  "schema": 1,
  "id": "standard-units",
  "revision": 1,
  "title": "Единицы измерения",
  "source": "Авторский учебный пример",
  "questions": [
    {
      "id": "length-01",
      "no": 1,
      "topic": "Длина",
      "text": "Сколько сантиметров в одном метре?",
      "options": [
        {"id": "ten", "text": "10"},
        {"id": "hundred", "text": "100"}
      ],
      "sourceKeys": ["hundred"],
      "keys": ["hundred"],
      "explanation": "Один метр содержит сто сантиметров."
    }
  ]
}
```

| Поле | Смысл |
| --- | --- |
| id и revision | Постоянный ID дисциплины и целая возрастающая редакция |
| questions[].id, no | Стабильный ID вопроса и отображаемый оригинальный номер. Они уникальны внутри редакции |
| topic, text, options | Учебная тема, полная формулировка и 2–16 вариантов со стабильными ID |
| sourceKeys | Исходные ключи. Для случая без ключа указывается пустой массив |
| keys | Принятые для оценки варианты. Пустой массив оставляет вопрос доступным для разбора. Несколько ID требуют точного совпадения всего множества |
| page, sourceNote | Страница и исходное пояснение |
| explanation, reference, url | Учебное пояснение, название акта с пунктом или статьёй, адрес источника по HTTPS |
| status, caveat, extra, reviewed | Статус проверки, замечание, ссылка на дополнительный источник, дата индивидуальной сверки в виде YYYY-MM-DD |

ID задаются латиницей, цифрами, точками, дефисами или подчёркиваниями, начинаются буквой либо цифрой и имеют длину до 64 знаков. Одна база содержит от 1 до 3000 вопросов. Порядок в options соответствует исходной нумерации. Цифра у варианта остаётся его исходным номером даже при перемешивании.

Для обновления сохраните ID дисциплины, увеличьте revision и сохраните ID вопросов, обозначающих те же задания. Для принципиально нового вопроса присвойте новый ID. Старые редакции сохраняются для разбора прошедших экзаменов. При изменении ключа или формулировки в существующем вопросе назначается новое закрепление. Попытки и пользовательские заметки сохраняются. Чтобы обновить базу с незавершённым экзаменом, сначала завершите билет.

Резервная копия использует формат exampro.backup версии 1. Для переноса прогресса нужен файл копии. Экспортированные отчёты exampro.stats и exampro.result предназначены для просмотра и анализа.
