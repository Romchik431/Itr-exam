# Экзамен ПРО

Автономное Android-приложение для обучения и тренировочных экзаменов. Версия 1.0.0, код 10000, идентификатор `by.exampro.itr`. Минимальная версия Android 9 (API 28), целевой SDK 35. APK содержит Java-код и локальный интерфейс для системного Android WebView. У приложения нет разрешения INTERNET. Основные режимы доступны с первой установки без сети.

## Работа на телефоне

1. Скопируйте или скачайте APK в «Загрузки». Откройте его через «Мои файлы» на Samsung либо системное приложение «Файлы». Выберите «Установить». Если Android предлагает разрешить установку из этого источника, решение относится только к выбранному файловому менеджеру. Обязательные политики организации и Knox учитываются системой.
2. Запустите «Экзамен ПРО» с экрана приложений. На главной доступны обучение, умная подготовка, экзамен, ошибки и карточки. Нижнее меню ведёт к вопросам, статистике и остальным разделам.
3. Откройте «Меню → План подготовки», укажите дату и минуты в день. Там же задаются локальное напоминание и время. Время доставки зависит от энергосбережения Android. Для произношения нужен установленный автономный русский голос.
4. Для переноса на другое устройство выберите «Настройки → Сохранить копию». Сохраните JSON через системный диалог. На новом устройстве выберите «Восстановить из файла» и подтвердите замену. Копия содержит заметки и подключённые базы. После удаления приложения Android очищает его внутренние данные.
5. Для обновления сохраните копию и откройте следующий подписанный APK поверх установленной версии. Android проверит пакет и подпись. Каталог пользовательских данных сохраняется при штатном обновлении.

## Архитектура и конфиденциальность

- `src/by/exampro/itr/MainActivity.java` управляет интерфейсом WebView, защищённым внутренним файлом состояния, системным выбором документов, печатью, передачей текстового итога, озвучиванием, режимом оформления и безопасными переходами к источникам.
- `StudyReminder.java` назначает ближайшее локальное уведомление через AlarmManager. Расписание восстанавливается после загрузки устройства, изменения времени и замены приложения. Для современных Android разрешение на уведомления запрашивается при включении.
- `assets/core.js` содержит проверку форматов, выбор вопросов, интервальное повторение, план, оценку и статистику. `assets/ui.js` связывает эти функции с экранами. `assets/style.css` и `res/` задают темы, значок и запуск.
- `assets/builtin.json` содержит встроенную дисциплину. Полная персональная поставка включает этот файл. В публичной ветке доступны движок и общий формат. В открытом CI используется отдельный синтетический набор.
- Данные хранятся во внутреннем каталоге приложения. Запись через Android AtomicFile заменяет состояние целиком. Перед импортом или сбросом создаётся точка восстановления. Проверяется структура, типы и диапазоны значений. Текущий формат состояния — 1. Неизвестная версия откроет режим восстановления с защитой исходной записи. Сохраните старый формат перед внедрением будущей миграции.
- Для внешних файлов используется Android Storage Access Framework. Разрешение на доступ ко всем файлам отсутствует. Контент JSON выводится как текст. В WebView разрешён фиксированный набор упакованных ресурсов. Ссылки открываются через внешний браузер после подтверждения. Рекламных, аналитических и сторонних исполняемых SDK нет.

## Сборка

Требуются Linux, JDK 17 или 21, Node.js 20+, Python 3, zip, Android Platform 35 (ревизия 2) и Android Build Tools 35.0.0. SDK предоставляет встроенные AAPT2, D8, zipalign и apksigner. Сборка не разрешает зависимости Gradle или Maven. В CI установите SDK командой `sdkmanager "platforms;android-35" "build-tools;35.0.0"`.

Выполните из каталога, содержащего папку android, с доступной базой и ключом владельца.

```bash
export ANDROID_HOME="$HOME/Android/Sdk"
export EXAM_KEYSTORE="/защищённый/каталог/exampro.p12"
export EXAM_PASS_FILE="/защищённый/каталог/release.pass"
node android/tests/core.test.js
bash android/tools/build.sh "./release/ExamPro.apk"
```

Переменная `EXAM_BANK` задаёт альтернативный файл базы. По умолчанию используется `android/assets/builtin.json`. Для проверки открытого кода можно получить синтетическую базу командой `node android/tests/core.test.js --fixture > /tmp/exam-fixture.json`. Запуск тестов интерфейса с полной базой требует Python Playwright, Chromium и при необходимости переменной `CHROMIUM_BIN`.

Каждый релиз получает больший versionCode и новый versionName в манифесте. Храните зашифрованный PKCS12 и пароль раздельно, вне Git. Имя записи ключа — exampro. Для личного релиза всегда используйте тот же ключ. Утрата ключа лишит возможности штатного обновления этого пакета поверх существующей установки. В публичном CI подпись служит только для проверки сборки. Сборка с данными предприятия выполняется локально в доверенной среде; автоматический выпуск предусмотрен также для закрытого репозитория при ручном запуске и наличии защищённых секретов. При передаче готового APK пользователю достаточно самого файла.

## Режимы и формат

Обучение, выбор нескольких тем, полнотекстовый поиск, сложные вопросы, закладки, избранное, заметки и история просмотров доступны через «Меню». Автоматические подборки учитывают пропуски, ошибки, время ответа и результат последних экзаменов. После раскрытия карточки выберите «Не знаю», «Сложно», «Хорошо» или «Легко». Для «Освоен» требуются успешные повторения в разные назначенные дни.

Настройки экзамена включают длину, темы, перемешивание, таймер, проходной балл и запрет возврата. В режиме со свободной навигацией можно отложить вопрос. Результат рассчитывается по всем вопросам билета, включая пропущенные. PDF формируется средствами системной печати Android. Текстом можно поделиться из итогов. Для передачи сохранённого PDF воспользуйтесь меню файла Android.

В комплекте есть описание независимых дисциплин и обновления редакций в FORMAT.md. Для включения иных дисциплин используйте проверенный JSON. Импорт CSV и Excel в этой версии требует предварительного преобразования в JSON. Эти форматы не обеспечивают однозначных связей между ключами, вариантами, источниками и редакциями без отдельной схемы.
